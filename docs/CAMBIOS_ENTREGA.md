# Ajustes de esta versión

- Se conservaron las páginas y funcionalidades React y Spring Boot existentes.
- Se añadió un enlace en Créditos al archivo original local de la portada.
- Se sustituyeron mensajes internos visibles por textos breves apropiados para visitantes, sin ocultar que los pagos y mensajes son de demostración.
- Se alineó el título de copyright y el README con el carácter académico no oficial del proyecto.
- Se retiraron capturas históricas, recursos de portada obsoletos, dependencias instaladas y documentos desactualizados del paquete para GitHub.
- Las tipografías ahora se cargan desde Google Fonts, con fuentes de respaldo; la apariencia específica requiere conexión a Internet.

La procedencia pública de la composición de portada no puede acreditarse únicamente con los archivos entregados. No se asignó una fuente externa ficticia.
- Se ajustó la longitud mínima configurable del administrador para la demostración local, sin incluir contraseñas en archivos públicos. Se recomienda una contraseña robusta para publicación.
- Se incluyeron descripciones iniciales de productos más naturales y se conserva la actualización de datos antiguos de MySQL.
